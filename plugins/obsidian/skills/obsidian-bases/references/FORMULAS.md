# Bases formulas and summaries

Formulas are expression strings keyed by name. Reference them through `formula.<name>`; avoid circular dependencies.

```yaml
formulas:
  age_days: '(now() - file.ctime).days.round(0)'
  due_label: 'if(due, date(due).format("YYYY-MM-DD"), "")'
properties:
  formula.age_days:
    displayName: Age in days
views:
  - type: table
    name: Dates
    order:
      - file.name
      - formula.age_days
      - formula.due_label
```

## Types and functions

| Input | Useful operations |
| --- | --- |
| Date | `date(value)`, `today()`, `now()`, `.format("YYYY-MM-DD")` |
| Duration | `.days`, `.hours`, `.minutes`, `.seconds`, `.milliseconds` |
| Number | `.round(digits)`, `.floor()`, `.ceil()`, `.toFixed(digits)` |
| String | `.contains(text)`, `.lower()`, `.trim()`, `.split(separator)` |
| List | `.filter(expression)`, `.map(expression)`, `.unique()`, `.join(separator)` |
| File | `.hasTag(tag)`, `.inFolder(folder)`, `.hasLink(target)`, `.asLink()` |

Subtracting two dates produces a Duration. Access a numeric field before rounding; do not treat it as raw milliseconds. Guard optional values before converting them to dates or performing arithmetic. A numeric-looking string is not necessarily a number.

Within list `filter` and `map` expressions, `value` is the current element and `index` is its position. Use only functions supported by the installed version; consult the [official function reference](https://help.obsidian.md/bases/functions) for signatures and additional operations.

## Summaries

Built-in summary identifiers such as `Average` can be assigned to displayed properties. Custom summaries are expressions over `values`:

```yaml
summaries:
  roundedAverage: 'values.mean().round(1)'
views:
  - type: table
    name: Estimates
    order:
      - file.name
      - note.estimate
    summaries:
      note.estimate: Average
```

The example declares a custom summary and assigns the built-in `Average` to the view. When assigning a custom summary, preserve the representation generated by the installed Obsidian version.

Check the relevant view's query output or rendering in Obsidian to verify property types, function support, and aggregate results. Valid YAML alone does not establish correct formula behavior.
